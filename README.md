# Financial-modelling   
   his project presents a comprehensive financial model of Infosys Ltd., built to evaluate the company’s financial performance, forecast future cash flows, and estimate intrinsic value using industry-standard valuation techniques.
The model covers historical financial analysis, ratio examination, revenue forecasting, cost estimation, and DCF valuation.
It is created for learning, portfolio demonstration, and showcasing financial analysis skills relevant for equity research, corporate finance, and investment roles.Key Features of the Financial Model

3-Statement Integrated Model
All financial statements are linked to ensure automatic updates.

Revenue & Cost Drivers
Forecasting based on:

IT service segment growth

Deal pipeline

Global digital spending trends

DCF Valuation

Free Cash Flow projections

WACC calculation

Terminal value using perpetual growth & exit multiple methodsData Sources Used
