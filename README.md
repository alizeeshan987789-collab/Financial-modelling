A comprehensive financial model of Infosys Ltd. to analyze historical performance, forecast future cash flows, and estimate intrinsic value using DCF and valuation multiples. Built for learning, portfolio demonstration, and showcasing skills in financial analysis, equity research, and corporate finance.Analyze historical financial statements (Income Statement, Balance Sheet, Cash Flow)

Build 5–10 year forecasts based on realistic assumptions

Estimate intrinsic value using Discounted Cash Flow (DCF)

Calculate key valuation multiples: PE, EV/EBITDA, Price-to-Sales

Provide insights on growth, profitability, liquidity, and shareholder value
